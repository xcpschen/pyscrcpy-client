# Python Scrcpy Client
This is a project for python scrcpy client fork from [scrcpy-client](https://github.com/leng-yue/py-scrcpy-client/tree/main). Added some features to make it more convenient to use.

## New Features
1. support callback function for raw h264 stream

## How to use
To begin with, you need to install this package via pip:
```shell
pip install pyscrcpy-client[ui]
```
Then, you can start `py-scrcpy` to view the demo:

Note: you can ignore `[ui]` if you don't want to view the demo ui
